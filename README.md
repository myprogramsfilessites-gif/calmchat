# CalmChat — голосовой чат по WebRTC

Общайтесь голосом с любого устройства (телефон, ПК) в одной комнате — без регистрации.

**Эхоподавление включено по умолчанию:** звук из динамиков/наушников не попадает в микрофон
(в браузере принудительно включаются `echoCancellation`, `noiseSuppression` и `autoGainControl`).

## Как работает

- Звук передаётся напрямую между устройствами через WebRTC (не через сервер).
- Для установки соединения нужен только сигнальный сервер (обмен адресами участников).
- По умолчанию используется бесплатный облачный сигнальный сервер PeerJS — поэтому сайт работает даже как статическая страница (GitHub Pages).

## Деплой (GitHub Pages)

Клиент уже развёрнут на GitHub Pages — просто откройте ссылку и введите имя комнаты на каждом устройстве.

## Запуск у себя (свой сигнальный сервер)

```bash
npm install
npm start
```

Откройте `http://localhost:3000?self=1` — страница использует ваш локальный сигнальный сервер.

## Структура

- `index.html`, `app.js`, `style.css` — клиент (работает и как статический сайт)
- `server.js` — опциональный сигнальный сервер (PeerServer) + раздача статики
